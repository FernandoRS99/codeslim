HTML organiza o conteúdo de uma página. Comece com um título e um parágrafo; depois troque os textos e veja o resultado.

O que cada tag faz?

<h1> marca o título principal deste exemplo.

<p> marca um parágrafo.

A tag de abertura inicia o elemento; a de fechamento usa uma barra, como </p>.

Como experimentar

  1. Copie o documento completo abaixo.
  2. Salve como index.html em um editor de texto, com codificação UTF-8.
  3. Abra o arquivo no navegador.
  4. Troque os textos de h1 e p, salve e atualize a página.

Documento completo

O head reúne informações do documento; o body contém o conteúdo exibido na página.

Baixar HTML
<!doctype html>
<html lang="pt-BR">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Minha primeira página</title>
  </head>
  <body>
    <h1>Minha primeira página</h1>
    <p>Estou aprendendo HTML com o CodeSlim.</p>
  </body>
</html>
